# ProjetPsinHistoire

Projet réalisé le 12 mai 2026 à Saint-Denis en HTML/CSS.

## 📖 Histoire

Lucas découvre un étrange fichier caché dans son ordinateur.  
Après l’avoir ouvert, son écran devient noir et un message inquiétant apparaît :

> « Tu n’aurais jamais dû ouvrir ce fichier. »

À partir de ce moment, tout change.

---

## 🖥️ Technologies utilisées

- HTML
- CSS

---

## 🎨 Ambiance du projet

Le projet utilise :
- une ambiance sombre,
- des effets visuels inquiétants,
- des animations de type glitch,
- une narration interactive.

---

## 📂 Structure

- `index.html` → introduction de l’histoire
- `page2.html` → découverte du message
- `page3.html` → premier choix du joueur

---

## 🚀 Lancer le projet

1. Télécharger les fichiers
2. Ouvrir `index.html` dans un navigateur
